# DeliveryRun Namespace Rules

- 기본 루트 네임스페이스: `DeliveryRun`
- Core/Infrastructure: `DeliveryRun.Core`
- Managers: `DeliveryRun.Managers.Core`, `DeliveryRun.Managers.Subs`
- Domain:
  - Delivery: `DeliveryRun.Delivery`
  - Music: `DeliveryRun.Music`
  - UI: `DeliveryRun.UI`
  - Data: `DeliveryRun.Data`

## Naming

- 파일명/클래스명: PascalCase
- 폴더명: PascalCase
